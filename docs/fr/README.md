# Parcours français — AvalancheGo

Nœud Avalanche, consensus, réseaux et chaînes virtuelles.

API, Snow, P-Chain, X-Chain, C-Chain et sous-réseaux.

Les validateurs échantillonnent le réseau jusqu’à convergence probabiliste.
